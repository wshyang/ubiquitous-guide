# CLAUDE.md — standing instructions for this repository

This repository adopts **GREENFIELD.md** (copied verbatim at the repo root) as its coding
discipline. Read `GREENFIELD.md` first; this file fills in the project-specific placeholders
and lists what is deliberately deferred.

## Project stack (fills GREENFIELD placeholders)

- Web app: TypeScript, Vite, HTML canvas (`src/`, `index.html`), tests with Vitest.
- Art pipeline: Python 3.11+ (`scripts/`), Pillow, NumPy, SciPy, OpenCV (headless), pytest.
  Pinned in `requirements-art.txt`.
- Source art lives in `src/images/` (never served). Pipeline outputs served by the app live in
  `public/assets/` and are regenerated by the scripts below.
- Browser screenshots for calibration: `scripts/screenshots/capture.mjs` (puppeteer-core, needs
  `CHROME_PATH`).

## Rules that apply here (from GREENFIELD.md)

1. **Record every decision as an addendum** in `docs/DECISIONS.md`, in the same change that makes
   the decision. Addenda are numbered `ADR-NNN` and never renumbered.
2. **Tests first, real inputs.** Image-processing functions are tested on synthetic arrays; no
   mocks of the file system or of image libraries. The sprite and composite manifests are
   regenerated from the real source sheets.
3. **Functions stay small**: at most 20 lines target, 50 hard limit; at most 3 parameters; guard
   clauses over nesting; no boolean flag parameters.
4. **Pure timing, deterministic frames.** Animation is a pure function of simulated time. Use
   `?t=<ms>` to freeze the clock for screenshots.
5. **Keep the scene's calibration values in `src/scene/layout.ts`** and the kayak/dragon-boat
   anchor tables in `scripts/composites/`. Change one value, regenerate, screenshot, inspect.
6. **Validate honestly.** Say which layer ran (unit, pipeline, or browser screenshot) and do not
   claim end-to-end coverage that did not run.
