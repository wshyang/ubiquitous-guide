# Scene Specification — Kallang Waterfront Animated Diorama

## Overview
Final artefact is a web app where entire scene is populated with elements and animated. Scene layers bottom→top:

1. **Sky**: gradient + drifting clouds
2. **Stadium backdrop**: Kallang Sports Hub dome (daytime turquoise backdrop as primary, sunset variants available)
3. **Promenade**: event props + characters
4. **Water**: dragonboats, kayaks, wakes, splashes

## Layers Detail

### Sky & Clouds
- Backdrop: `public/images/backdrop-sky-gradient-blue.jpg` tiled + `public/images/backdrop-kallang-*` for stadium
- Clouds: 8 instances from `cloud-small-*.png` + `cloud-large-*.png` drifting via `drift` keyframes (30-80s duration, staggered delay, varying scale 0.4-0.8, opacity 0.7-1.0)
- Animation loop: `drift` from -200px to 100vw+200px linear infinite — creates parallax without JS

### Stadium Backdrop
- Primary: `backdrop-kallang-daytime-turquoise.jpg` (turquoise water variant) object-cover top
- Overlay title "THE KALLANG 🇸🇬" in pixel font, black 60% backdrop
- Variant backdrops available at `/images/backdrop-*` for theming (sunset magenta/orange, populated crowded) — toggle via prop (future)

### Promenade Props
- From `public/sprites/organized/*tent*.png`, `arch-start-finish.png`, `arch-balloon-rainbow.png`, `banner-psd-red.png`, `bunting-triangles.png`, `podium-123.png`, `barrier-metal.png`
- Static placement: tents 38% left, arches 62%/80% left, podium 70% etc. (see Props.jsx)
- Future: randomise via seed

### Characters
- 6 colourways × idle/run/cheer sprites extracted to `public/sprites/characters/*.png`, aliased in `organized/character-*-front-idle.png`
- On promenade: `CharacterStrip` 14 avatars bobbing (`character-bob` 0.8s), `WalkingCrowd` 10 walkers drifting across promenade (drift 18-26s)
- Animation loop: bob + drift; varied by colour + delay; future: sprite-sheet steps() for walk cycle using run1/run2 frames

### Water & Boats
- Water surface: gradient cyan→teal + shimmer repeating-linear-gradient `wave` 2s + bob line
- **Dragonboats**: 3 instances (red, blue, green) at bottom 24%/42%/60% with drift 18-26s, scale 0.20-0.23, oar animation 0.9s stagger 0.09s per rower (see anchors.js)
- **Kayaks**: 6 instances K1/K2/K3 variants at bottom 8%-70% with drift 13-19s (some reverse direction via scaleX(-1)), paddle animation 0.6s ±38° center pivot, stagger 0.2-0.3s per paddler
- **Wakes & Splashes**: `wake-medium.png`, `wake-small-1.png` behind boats with bob 2s, plus `Splash` radial divs with `splash` 0.9s scale/fade

## Animation Loops Summary

| Element | Loop | Duration | Variation |
|---------|------|----------|-----------|
| Clouds drift | drift left→right | 30-80s | size, opacity, top, delay |
| Dragonboat oar row | oar-row rotate | 0.9s | phase per rower 0-0.45 stagger |
| Kayak paddle | paddle-kayak rotate | 0.6s | phase per cockpit 0/0.5/0.33 |
| Boat translation | drift across water | 13-26s | lane, direction, speed, scale |
| Character bob | character-bob y | 0.8s | delay per avatar |
| Walker drift | drift across promenade | 18-26s | duration, top |
| Water shimmer | wave x | 2s | opacity |
| Splash | splash scale+fade | 0.9s | position, delay |
| Wake bob | bob y | 2s | opacity |

All loops are CSS keyframes (GPU-accelerated transforms) — no JS per-frame except optional now ticker. Varies sprites via random selection from 11 uniques: 6 dragon colours, 6 kayak variants, 8 cloud types, 6 character colours, 4 tent colours, etc. Staggered delays ensure no synchronised repetition.

## Public URL Paths
- Originals: `/images/<meaningful-filename>.jpg` (src/images → public/images copy)
- Sprites raw: `/sprites/<category>/<file>.png` (characters/boats/clouds/waterfx/props)
- Sprites organised: `/sprites/organized/<semantic-name>.png` (human-friendly aliases)
- Manifest: `/sprites/manifest.json` (auto-generated by extract_sprites.py, lists bbox/size/file for all 491 sprites)
- Backdrops: `/images/backdrop-*.jpg`, `/images/reference-photo-*.png`

## Responsiveness
- Container `h-screen w-full overflow-hidden`, layers use % positioning, hull sizes scale via `scale` prop (pixelated rendering, crisp-edges)
- Font: Press Start 2P pixel font
